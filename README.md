# Как я провёл лето — армия

Статический веб-сайт — рассказ о лете, проведённом в армии. Сделан в рамках
лабораторной работы № 1 по дисциплине «Web-технологии».

## 🛠️ Технологии

- **HTML5** — семантическая разметка;
- **CSS3** — собственные стили в `css/style.css`;
- **Bootstrap 5.3.3** — сетка, навбар, кнопки, утилитарные классы;
- **AOS 2.3.1** — анимации появления секций при скролле;
- **JavaScript** — навигация, управление фоновым аудио, эффект «проявляющейся» шапки;
- **Git / GitHub** — контроль версий и публикация.

## 🚀 Запуск

Проект не требует сборки и не использует серверную часть — достаточно
открыть `index.html` в браузере.

Для локального запуска с «живой» перезагрузкой удобно использовать
расширение **Live Server** в VS Code:

1. Откройте папку проекта в VS Code (**File → Open Folder**).
2. Правый клик на `index.html` → **Open with Live Server**.
3. Страница откроется по адресу `http://127.0.0.1:5500/index.html`.
